# Notices

## Gridfinity

Gridfinity is an open-source modular storage system created by Zack Freedman.
This add-in generates bins that follow the community Gridfinity specification:

- Gridfinity specification and design reference drawing (credit: willtree8):
  https://gridfinity.xyz/specification/
- Dimensions cross-checked against kennetek/gridfinity-rebuilt-openscad:
  https://github.com/kennetek/gridfinity-rebuilt-openscad

No code or model files from those projects are included; only the published
dimensions (grid pitch, height unit, clearance, foot and lip profile, magnet
and screw hole sizes) are used.

This project isn't affiliated with or endorsed by the Gridfinity creator or
the projects above.
