# Changelog

## 1.0.0

First release.

- Palette UI: grid sizing in 42 mm / 7 mm units, compartment editor (click or drag, quick split, 1 / ½ / ⅓ / ¼ unit grid, undo/redo), live 3D preview.
- Spec-accurate feet and optional stacking lip; parametric base with named user parameters.
- Label tabs (depth, angle, width, alignment), finger scoops, magnet and/or screw holes (every foot or outer corners).
- Create in a new document, update in place (one undo step), optional auto-update.
- Read-back verification after every build, including volume against the spec value.
- STL, 3MF and STEP export with versioned file names.
- Saved layouts and settings in a per-user data folder.
- Unit tests, a Python/JavaScript parity test, and a Fusion integration test with a stacking check.
